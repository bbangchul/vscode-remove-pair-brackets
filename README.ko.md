# Remove Pair Brackets

커서를 감싸는 가장 가까운 `()`, `[]`, `{}`의 괄호 두 개만 삭제하고, 내부 내용은 유지하는 VS Code 확장입니다.

**Mac 기본 단축키: ⌘ + Delete (Command + Backspace)**

## 사용 예시

`func(a + (b * c))`에서 `c` 뒤, 내부 닫는 괄호 앞에 커서를 두고 **⌘+Delete**를 누르면 `func(a + b * c)`가 됩니다.

`({[value]})`의 `value` 안에서 실행하면 `({value})`가 됩니다. 중첩된 괄호 중 가장 가까운 쌍만 삭제합니다.

## 설치

[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=SeongCheolBang.remove-pair-brackets)에서 설치하거나, `npm run package`로 VSIX 파일을 만듭니다. VS Code에서 **⇧⌘P → Extensions: Install from VSIX...**를 선택하고 해당 파일을 설치합니다. 필요한 경우 창을 다시 로드하세요.

## 동작

- 여는 괄호 바로 뒤, 닫는 괄호 바로 앞뿐 아니라 닫는 괄호 바로 뒤에서도 해당 쌍을 삭제합니다. 빈 괄호도 지원합니다. 중첩 괄호에서 안쪽 닫는 괄호 바로 뒤에 커서를 놓으면 안쪽 쌍을 삭제합니다.
- 커서를 감싸는 짝이 없으면 아무것도 삭제하지 않습니다.
- 여러 커서의 괄호를 한 번에 삭제하며, 같은 쌍은 한 번만 삭제합니다.
- 선택 영역이 있으면 선택의 활성 끝점을 기준으로 쌍을 찾습니다. 선택한 내용은 유지합니다.
- **⌘Z** 한 번으로 한 명령의 변경 전체를 복구할 수 있습니다.
- 기본 단축키는 Mac의 편집 가능한 텍스트 편집기에서 적용됩니다. 다른 운영체제에서도 명령 팔레트로 실행하거나 단축키를 직접 지정할 수 있습니다.

## 단축키 변경

**⌘K 누른 뒤 ⌘S**로 키보드 단축키 설정을 열고 **Remove Pair Brackets**를 검색합니다. 명령을 더블클릭한 뒤 원하는 조합을 누르고 Enter로 저장하세요.

기본 ⌘+Delete는 기존의 줄 시작까지 삭제 동작을 대체합니다. 괄호가 없으면 원래 삭제 동작으로 돌아가지 않고 아무것도 하지 않습니다. 사용자 지정 단축키가 우선하며, 예전에 이 명령에 직접 지정한 단축키는 확장을 업데이트해도 유지됩니다.

Mac 키보드의 뒤로 삭제하는 Delete 키는 VS Code에서 `backspace`로 표현하므로 코드에는 `cmd+backspace`로 등록됩니다. `Fn+Delete`로 입력하는 앞으로 삭제 키와는 다릅니다.

## 매칭 범위

언어 파서 없이 텍스트의 괄호 문자를 매칭합니다. 문자열·주석·정규식 안의 괄호도 포함되므로 코드 문법상의 쌍과 다를 수 있습니다. 교차하거나 짝이 맞지 않는 괄호는 쌍으로 취급하지 않습니다.
