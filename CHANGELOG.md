# Changelog

## 0.1.3

- Allow removing a pair with the cursor immediately after its closing bracket, including nested pairs.

## 0.1.2

- Add an extension icon featuring a pair of parentheses and an insertion cursor.

## 0.1.1

- Change the default macOS shortcut to Command + Delete (`cmd+backspace`).
- Add public documentation in English and Korean, including shortcut customization and matching limitations.

## 0.1.0

- Remove the nearest enclosing `()`, `[]`, or `{}` without deleting its contents.
- Support nested pairs, multiple cursors, and single-step undo.
